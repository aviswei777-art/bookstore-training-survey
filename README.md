# 書店 9 月課程提報與同仁職類調查

以 React、Vite 與 Tailwind CSS 製作的六步驟響應式問卷展示版。

## 本機預覽

```bash
npm install
npm run dev
```

開啟終端顯示的網址（通常為 `http://localhost:5173`）。開發伺服器已綁定 `0.0.0.0`，在容器或遠端工作區可直接使用其「Ports／連接埠」功能轉發 5173 埠。正式建置可執行 `npm run build`，並以 `npm run preview` 預覽。

## 資料與儲存

- 店別與同仁假資料集中於 `src/data/stores.json`。
- 課程場次及職類選項集中於 `src/data/options.json`。
- 草稿自動存入瀏覽器 LocalStorage；送出後返回首頁會清除舊草稿，方便重新填寫。
- 展示版不會傳送資料至伺服器或 Google Sheet。

## 第一版實作假設

1. 法律課程依規格先提供一列新增人員欄位，場次以三個選項呈現，「參訓場次需求」保留自由文字以便說明限制。
2. 包裝課程主提報人為一名，候補名單使用同一個多行欄位，可用頓號分隔多人。
3. 職類調查每位同仁皆可複選；選取「其他」後才顯示補充欄位。
4. 除店別必選外，其餘頁面依規格不設阻擋條件；送出僅保存於瀏覽器。
5. 瀏覽器原生離頁警告的實際文字由各瀏覽器安全政策決定，應用會在未提交草稿存在時觸發警告。
